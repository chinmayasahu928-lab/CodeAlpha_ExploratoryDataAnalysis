# CodeAlpha Task 2 – Exploratory Data Analysis (EDA)

## 📌 Objective

Perform Exploratory Data Analysis on the **1,000 Books dataset** collected in Task 1.

## 🛠️ Tools Used

* Python
* Google Colab
* Pandas
* NumPy
* Matplotlib
* Seaborn

## 📂 Dataset

The dataset contains information about:

* Book Title
* Price
* Rating
* Availability
* Book URL

## 🔍 EDA Performed

* Checked rows and columns
* Checked missing values
* Checked duplicate records
* Analyzed book prices
* Analyzed book ratings
* Calculated basic statistics
* Compared price and rating
* Created charts and graphs

## 📊 Visualizations

* Price Distribution
* Rating Distribution
* Price vs Rating
* Price Box Plot

## 💡 Key Insights

The analysis helps understand **book prices, ratings, availability, and their patterns**.
